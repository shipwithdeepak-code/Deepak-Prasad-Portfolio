## How I Built This

Built as a high-performance web platform combining product storytelling and interactive architectural demonstrations:
- **Core Stack**: React 18, Vite, and TypeScript with Tailwind CSS
- **Application Server**: Express (`server.ts`) serving production assets and real-time backend API endpoints
- **AI & Retrieval**: Google AI Studio & Gemini API (`@google/genai`) powering an in-memory RAG copilot grounded strictly in verified career artifacts
- **Deployment & CI/CD**: Automated deployment via GitHub Actions
